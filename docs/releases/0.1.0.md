# iStick2War — Release notes (v0.1.0)

**Version:** 0.1.0 Early Access  
**Save format:** `run_save.json` format version **1**  
**Document type:** Mini product doc — release notes + QA plan + release gate + save-format reference. Canonical document for v0.1.0 Early Access.

> **iStick2War** is a wave-based bunker defense shooter inspired by classic Flash-era action games. This Early Access build introduces a complete **Settings** system and **persistent run saving** — pause mid-run, return to the main menu, and continue where you left off.

**Current development phase**


## English

### What's new

#### Settings menu

Open **Settings** from the main menu. All options are saved automatically (PlayerPrefs) and applied on next boot.

**Audio**
- **Master Volume** — overall mix level
- **Music Volume** — menu / gameplay / boss music
- **SFX Volume** — weapons, impacts, UI, explosions

**Graphics**
- **Fullscreen** — toggle exclusive fullscreen window
- **Resolution** — pick supported desktop resolution (applied immediately)
- **VSync** — vertical sync on/off
- **FPS Limit** — frame-rate cap (Unlimited / 30 / 60 / 120)

**Gameplay**
- **Screen Shake** — world camera shake on hits and explosions
- **Mouse Sensitivity** — scales hero aim from screen center

Use **Back** to return to the main menu (Start / Settings buttons restore correctly).

---

#### Pause, save, and continue

- **Pause button** (in-game) — saves your run, pauses the game, and returns to the main menu
- **Continue** (main menu, when a save exists) — resume wave progress, currency, bunker HP, lives, and weapon loadout
- **Start Game** — begins a **new run** and clears the active save

**How saving works** *(documented like a small API — use for QA triage and support)*

| Topic | Detail |
|-------|--------|
| **File location** | `Application.persistentDataPath/iStick2War_V2/run_save.json` |
| **When autosave runs** | Pause to menu, app quit/pause, wave complete (shop), wave start, life-over, and similar safe checkpoints |
| **What is saved** | Wave index, currency, bunker HP/max, lives, shop counters, loop state (shop / preparing / in-wave / life-over), hero HP, weapon loadout and ammo |
| **What is not saved** | Enemy positions, projectiles, particles, AI state, mid-wave battlefield layout |
| **Mid-combat rule** | **Mid-combat saves keep your run stats but restart the current wave with fresh enemy spawns** |
| **When save is cleared** | **game over**, **victory** (run complete), or **Start Game** (new run) |
| **Versioning** | `formatVersion` in file; older saves migrated via `RunSaveMigration_V2` on load |

**Support / triage:** If a player reports *"I paused mid-wave and the enemies were gone"*, that is **by design** — see **What is not saved** and **Mid-combat rule** above.

---

#### Survival mode (EA)

**Start Survival** from the main menu for an endless run. Waves scale after wave 15; **Game Won** does not trigger. Best wave and total kills are stored for the **High Score** panel.

**Between waves (Survival only)** — instead of the shop:

1. A neutral **Swedish supply plane** flies across the battlefield.
2. It drops a parachute **powerup** near the bunker lane (random roll from the survival catalog).
3. You can **move the hero** during this short pass to pick up the crate.
4. Pickups can restore **health**, **repair the bunker**, **unlock or refill weapons**, or **refill ammo** (weighted table in `SurvivalPowerUpCatalog_V2`).
5. When the plane leaves, the next wave prepares automatically.

**Campaign** still uses the **shop** between waves. Survival uses wave reward currency but does not open the shop panel.

**QA / editor:** `SwedishPlaneSurvivalCoordinator_V2` on `WaveManager_V2`; prefabs `SwedishPlane` + `SwedishPlane_PowerUp`; dev shortcut **Open Swedish Plane Supply Directly** on `WaveConfig_V2` (wave 1) for isolated testing.

#### Survival mode (EA)

**Start Survival** i huvudmenyn startar en endless-run. Vågor skalar efter våg 15; **Game Won** triggas inte. Bästa våg och totala kills sparas i **High Score**.

**Mellan vågor (endast Survival)** — i stället för shop:

1. Ett neutralt **svenskt försörjningsflyg** flyger över spelplanen.
2. Det släpper en fallskärms-**powerup** nära bunkerbanan (slumpad roll från survival-katalogen).
3. Du kan **röra hjälten** under passet och gå till lådan för att plocka upp den.
4. Powerups kan ge **HP**, **bunker-reparation**, **vapen-unlock/refill** eller **ammo** (`SurvivalPowerUpCatalog_V2`).
5. När flygplanet lämnat skärmen förbereds nästa våg automatiskt.

**Campaign** använder fortfarande **shop** mellan vågor. Survival ger vågbelöning men öppnar inte shop-panelen.

**Täckning:** huvudmeny (`OrthographicCameraAspectFitter_V2`, `MainMenuCanvasLayout_V2`), Settings (`SettingsCanvasLayout_V2`), HUD (`HUD-Canvas` + `HUD-Sprites-Canvas`, döljs i shop), shop/Life Over/Game Over (scene-canvas), gameplay-droppzoner (`CombatBand_4x3` / `_16x9` / `_21x9` under `CombatBands`), loot-rensning mellan vågor.

**Officiell Game View QA-matris** — kör smoke på varje preset före EA-kandidater:

| Game View-preset | Aspect | Aktivt combat band | Snabbkoll |
|------------------|--------|-------------------|-----------|
| Desktop / Full HD / QHD / 4K / 16:9 Aspect | 16:9 | `CombatBand_16x9` | HUD, shop, bunker centrerat; dropp inom blå band |
| Blue Safe Area (1024×768) | 4:3 | `CombatBand_4x3` | Settings + HUD läsbar; inga klippta stats |
| Ultrawide (2560×1080) | 21:9 | `CombatBand_21x9` | Extra bredd utnyttjas; dropp inte låsta till 16:9 |
| Steam Deck (1280×800) | 16:10 | `CombatBand_16x9` (närmast) | Spelbart; eget 16:10-band bara om playtest kräver |
| iPhone landscape (2532×1170) | ~19.5:9 | `CombatBand_21x9` (närmast) | HUD safe area |

Fullständig EN-version (mekanismer, gaps, nyckelskript): se **Resolution scaling (locked)** ovan.

### Release gate (EA 0.1.0)

**När är builden shippable?** Gå igenom checklistan före varje EA-kandidat. Om något fallerar är builden inte klar — fixa eller skjut upp, lägg inte till features för att kringgå gate.

| Gate | Täcker |
|------|--------|
| **Setup** | Pausknapp och Continue kopplade i scener |
| **Gameplay** | Campaign våg 1–15, boss, shop, vapen, life-over-flöden |
| **Survival** | Endless vågor, skalning, high score, meny + High Score; **svenskt supply-flyg + powerup-pickup** (ingen shop mellan vågor) |
| **Save / load** | Paus/avslut → continue; nytt spel / game over / vinst rensar save (per läge) |
| **UI / settings** | Sliders, skärmalternativ, Continue-synlighet, Settings → Back |
| **Balans** | Ekonomi och tryck över 15 vågor (pågående) |

Markera i Play Mode om inget annat anges.

**Detaljerad manuell QA:** [docs/qa/0.1.0-manual-qa.md](../qa/0.1.0-manual-qa.md) (fasindelad checklista för rc2).

**Setup (editor)**
- [x] `pauseButton`-prefab placerad i `SampleScene` *(HUD-Canvas — verifiera per build)*
- [ ] Continue-knapp kopplad i `MainMenuScene` (`TextBTN_MediumContinue` eller motsvarande UI)

**Gameplay-checklista**
- [ ] Våg 1–15 spelbara från start till slut *(15 assets kopplade; 11–15 behöver balans-QA)*
- [ ] Boss kan besegras
- [ ] Alla vapen skjuter, laddar om och unlockas i shop korrekt
- [ ] Shop-köp fungerar (hp, bunker, vapen, ammo)
- [ ] Life-over → retry / shop-flöden fungerar *(fixar landade — full genomgång behövs)*
- [ ] Game over efter 3 dödsfall visar UI och restart/continue fungerar

**Survival-checklista**
- [ ] **Start Survival** startar endless run (`Survival · Wave N` i HUD)
- [ ] Ingen Game Won efter v15; vågor fortsätter med skalning
- [ ] Game Over sparar bästa våg + kills (`SurvivalHighScoreService_V2`)
- [ ] **High Score**-panel + **Go Back** fungerar
- [ ] Paus → Continue återställer Survival (`gameMode` i save)
- [ ] Campaign vs Survival startar rätt läge och rensar save
- [ ] Efter klar våg: **ingen shop**; **svenskt flyg** kör supply-pass i stället
- [ ] Flygplanet släpper **powerup**; hjälten kan röra sig och **plocka upp** lådan (HP / bunker / vapen / ammo)
- [ ] Nästa våg startar efter passet; Campaign-shop oförändrad

**Save / load-checklista**
- [ ] Paus → huvudmeny → Continue återställer omgången
- [ ] Avsluta mitt i våg → starta om → Continue återställer omgången
- [ ] Start Game raderar save
- [ ] game over raderar save
- [ ] vinst raderar save
- [ ] Spar mitt i combat startar om vågen med behållen stats (avsiktligt)

**UI / settings-checklista**
- [ ] Alla volym-sliders sparas och verkar
- [ ] Fullscreen, upplösning, VSync, FPS-limit fungerar efter omstart
- [ ] Screen shake-toggle påverkar gameplay
- [ ] Mus-känslighet påverkar sikte
- [ ] Continue syns bara när save finns
- [ ] Settings → Back återställer huvudmeny-knappar och texter

**Balans (pågående)**
- [ ] Genomgång av ekonomi och fiendetryck över 15 vågor
