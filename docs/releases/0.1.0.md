## English

### What's new

#### Settings menu

Open **Settings** from the main menu. All options are saved automatically (PlayerPrefs) and applied on next boot.

**Audio**
- **Master Volume** — overall mix level
- **Music Volume** — menu / gameplay / boss music
- **SFX Volume** — weapons, impacts, UI, explosions

**Graphics**
- **Fullscreen** — toggle exclusive fullscreen window
- **Resolution** — pick supported desktop resolution (applied immediately)
- **VSync** — vertical sync on/off
- **FPS Limit** — frame-rate cap (Unlimited / 30 / 60 / 120)

**Gameplay**
- **Screen Shake** — world camera shake on hits and explosions
- **Mouse Sensitivity** — scales hero aim from screen center

Use **Back** to return to the main menu (Start / Settings buttons restore correctly).

---

#### Pause, save, and continue

- **Pause button** (in-game) — saves your run, pauses the game, and returns to the main menu
- **Continue** (main menu, when a save exists) — resume wave progress, currency, bunker HP, lives, and weapon loadout
- **Start Game** — begins a **new run** and clears the active save

**How saving works** *(documented like a small API — use for QA triage and support)*

| Topic | Detail |
|-------|--------|
| **File location** | `Application.persistentDataPath/iStick2War_V2/run_save.json` |
| **When autosave runs** | Pause to menu, app quit/pause, wave complete (shop), wave start, life-over, and similar safe checkpoints |
| **What is saved** | Wave index, currency, bunker HP/max, lives, shop counters, loop state (shop / preparing / in-wave / life-over), hero HP, weapon loadout and ammo |
| **What is not saved** | Enemy positions, projectiles, particles, AI state, mid-wave battlefield layout |
| **Mid-combat rule** | **Mid-combat saves keep your run stats but restart the current wave with fresh enemy spawns** |
| **When save is cleared** | **game over**, **victory** (run complete), or **Start Game** (new run) |
| **Versioning** | `formatVersion` in file; older saves migrated via `RunSaveMigration_V2` on load |

**Support / triage:** If a player reports *"I paused mid-wave and the enemies were gone"*, that is **by design** — see **What is not saved** and **Mid-combat rule** above.

### Nytt i den här builden

#### Inställningsmeny

Öppna **Settings** från huvudmenyn. Alla val sparas automatiskt (PlayerPrefs) och laddas vid nästa start.

**Audio**
- **Master Volume** — total ljudnivå
- **Music Volume** — meny-, gameplay- och bossmusik

**Back** stänger inställningarna och visar huvudmenyn igen.

---

#### Paus, sparning och fortsätt

- **Pausknapp** (i spelet) — sparar spelomgången, pausar och går till huvudmenyn
- **Continue** (huvudmeny, när save finns) — återställer våg, pengar, bunker-HP, liv och vapen
- **Start Game** — **ny spelomgång** (raderar aktiv save)

**Så fungerar sparning** *(dokumenterat som ett litet API — för QA och support)*

| Ämne | Detalj |
|------|--------|
| **Filplats** | `Application.persistentDataPath/iStick2War_V2/run_save.json` |
| **När autosave sker** | Paus till meny, app-avslut/paus, våg klar (shop), vågstart, life-over m.m. |
| **Vad som sparas** | Vågindex, pengar, bunker-HP/max, liv, shop-räknare, loop-läge, hjälte-HP, vapen och ammo |
| **Vad som inte sparas** | Fiendepositioner, projektiler, partiklar, AI-state, exakt stridsfält |
| **Regel mitt i combat** | **Spar mitt i combat behåller din progress men startar om vågen med nya fiender** |
| **När save raderas** | **game over**, **vinst** (run complete), eller **Start Game** (ny omgång) |
| **Versionering** | `formatVersion` i filen; äldre saves migreras via `RunSaveMigration_V2` vid load |

**Support / triage:** Om någon rapporterar *"Jag pausade mitt i en våg och fienderna var borta"* — **avsiktligt enligt design**, se **Vad som inte sparas** och **Regel mitt i combat** ovan.
