# Manuell QA — v0.1.0 (rc3)

Detaljerad checklista för Play Mode-test av **iStick2War** mot EA 0.1.0 release gate.

| | |
|---|---|
| **Baseline-tag** | `v0.1.0-rc3` (eller senaste `master` efter taggen) |
| **Release notes** | [docs/releases/0.1.0.md](../releases/0.1.0.md) |
| **Save-fil** | `Application.persistentDataPath/iStick2War_V2/run_save.json` |
| **Google Sheets** | [google-sheets/IMPORT-GOOGLE-SHEETS.md](google-sheets/IMPORT-GOOGLE-SHEETS.md) (CSV → importera till Sheets) |

Kör i **prioriterad ordning** nedan. Tidiga faser stoppar dig om något fundamentalt är trasigt.

---

## Förberedelse

- [ ] Checkout `v0.1.0-rc3` eller senaste `master` efter taggen
- [ ] (Valfritt) Radera gammal save för ren start
- [ ] Anteckningsfil redo: PASS / FAIL / steg / screenshot
- [ ] Första pass i **Desktop 1920×1080**; resolution-matris i **Fas 11** sist eller parallellt

---

## Fas 1 — Setup & huvudmeny (~15 min)

### 1.1 Scen-kopplingar (Editor, en gång per build)

- [ ] `SampleScene`: pause-knapp syns under `HUD-Canvas` / TopLeft i Play
- [ ] `MainMenuScene`: **Continue**-knapp finns och är kopplad (`TextBTN_MediumContinue` eller motsvarande)

### 1.2 MainMenuScene — kall start (ingen save)

- [ ] **Start Campaign** (eller **Start Game**) startar Campaign
- [ ] **Start Survival** startar Survival (endless)
- [ ] **High Score** öppnar panel; **Go Back** till meny
- [ ] **Settings** öppnas
- [ ] **Continue** är dold eller inaktiv när ingen save finns
- [ ] Alla knappar går att klicka (inga döda hitboxes; ingen överlappad layout)

### 1.3 MainMenuScene — med save

- [ ] Spela ~30 s → **Pause** → tillbaka till huvudmeny
- [ ] **Continue** syns nu
- [ ] **Continue** återupptar samma våg med rätt currency / HP / liv (grovt)

### 1.4 MainMenuScene — introfilm (~10 min)

Kräver `MainMenuIntroVideoBackground_V2` på **Main Menu V2** med **Intro Clip** = `Assets/Prefabs/IntroMovie/MainMenuIntroMovie.mp4`, samt UI-objekt **`loadingBackground`** under **MainMenu-canvas**.

- [ ] Vid start: **`loadingBackground`** syns medan videon laddas; knappar i **SafeAreaRoot** är dolda
- [ ] Ingen blå/lucka med synliga knappar mellan loading och video (svart kamera-OK under kort gap)
- [ ] Introfilmen loopar som bakgrund; **ingen ljud** från MP4 (menymusik spelar)
- [ ] När videon syns: menykknappar i **SafeAreaRoot** visas; statisk `bkg_main_menu`-sprite döljs
- [ ] **Start Campaign / Survival / Settings / High Score** fungerar efter att intro laddat

## Fas 2 — Settings (~30 min)

Öppna Settings från huvudmenyn. Starta om spelet efter grafiktest om det anges.

### 2.1 Audio

- [ ] **Master Volume** — hörbart lägre/högre direkt
- [ ] **Music Volume** — menymusik påverkas
- [ ] **SFX Volume** — UI-klick / vapen påverkas i gameplay
- [ ] Stäng spelet helt → starta om → värden kvar

### 2.2 Graphics

- [ ] **Fullscreen** — växlar fönster/fullskärm
- [ ] **Resolution** — byt upplösning; bilden ändras
- [ ] **VSync** — på/av (kolla tearing eller cap)
- [ ] **FPS Limit** — Unlimited / 30 / 60 / 120 känns rimligt
- [ ] Starta om spelet → val kvar

### 2.3 Gameplay-inställningar

- [ ] **Screen Shake** AV — mindre/inte skak vid träffar
- [ ] **Screen Shake** PÅ — skak tillbaka
- [ ] **Mouse Sensitivity** — låg vs hög påverkar sikte märkbart

### 2.4 Navigation

- [ ] **Back** → huvudmeny med Start / Settings / Continue synliga och klickbara
- [ ] Parchment/layout OK i **Blue Safe Area (1024×768)** — ingen klippt text

## Fas 3 — Gameplay HUD & pause (~20 min)

Starta nytt spel. Våg 1, Desktop 16:9.

### 3.1 HUD under våg

- [ ] Topbar: HP, ammo, vapen, bunker, vågnummer syns
- [ ] **Pause** (uppe vänster) syns och klickbar
- [ ] **Hjärtan** (uppe höger) visar 3 liv
- [ ] HUD **försvinner** när **Campaign-shoppen** öppnas efter våg
- [ ] HUD **kommer tillbaka** när nästa våg startar
- [ ] HUD **syns under Survival supply-pass** (SwedishPlane) — samma topbar som under våg

### 3.2 Pause → save

- [ ] Pause → huvudmeny (spelet pausas/sparas)
- [ ] Continue → samma våg, samma stats (ungefär)
- [ ] **Förväntat vid pause mitt i våg:** fiender kan vara borta vid continue — **by design** (vågen startar om, stats behålls)

## Fas 6 — Fiender & flyg (~30 min)

### 6.1 Paratrooper

- [ ] Skjuter åt rätt håll (inte baklänges)
- [ ] MP40/helmet drop vid död — rimlig höjd på marken
- [ ] Fallskärm **försvinner** efter granatkast
- [ ] **Loot försvinner** när vågen är klar (innan shop)
- [ ] Staplade paratroopers i glide: ingen flicker/sortering-kaos *(retest)*

### 6.2 Flyg

- [ ] Bomb drone utanför skärm — försvinner/ej soft-lock (~5 s)

- [ ] Flygljud hörs; notera om för tyst *(känd issue)*

### 6.3 Explosioner

## Fas 7 — Life Over (~30 min)

Du har **3 liv**. Dö med liv kvar:

### 7.1 Första / andra döden

- [ ] **~3 sekunders delay** innan Life Over visas (inte instant)
- [ ] Life Over UI syns och är läsbart
- [ ] **Go to Shop** fungerar → shop öppnas
- [ ] **Retry / Start Game** (samma våg) fungerar
- [ ] **Go to Main Menu** fungerar; save finns kvar för Continue

### 7.2 Efter life-over → shop → retry

- [ ] Retry startar om samma våg
- [ ] Bunker kan vara fullad vid retry (enligt design)
- [ ] Loot/projektiler rensade vid life retry

---

## Fas 8 — Game Over (KRITISK, ~20 min)

### 8.1 Naturlig väg (3:e döden)

- [ ] Förlora liv 1 → Life Over → retry
- [ ] Förlora liv 2 → Life Over → retry
- [ ] Förlora liv 3 → **Game Over UI** visas
- [ ] Game Over-panel **synlig och klickbar**
- [ ] Restart / continue-alternativ fungerar (om de finns)
- [ ] Save **raderas** efter game over
- [ ] Huvudmeny: **Continue** borta efter game over

### 8.2 Dev-genväg (om tillgänglig)

- [ ] `WaveConfig` med **Open GameOver Directly** → Game Over UI direkt
- [ ] Samma klickbarhet som ovan

> **Release blocker:** Om 8.1 failar är builden inte EA-klar.

## Fas 14 — Survival mode (~45 min) — **EA-krav**

### 14.1 Start & HUD

- [ ] **Start Survival** → `SampleScene`; HUD visar `Survival · Wave 1` (eller motsvarande)
- [ ] Ingen Game Won efter våg 15 — spelet fortsätter till Game Over

### 14.2 Endless loop & skalning

- [ ] Dev-shortcut eller AutoHero: nå minst våg 16 (wrap/skalning känns hårdare, inget soft lock)
- [ ] **Ingen shop** mellan vågor i Survival (Campaign-shop oförändrad)
- [ ] **HUD-Canvas syns** medan supply-flyget flyger in (inte dolt som i shop)
- [ ] Efter klar våg: **svenskt supply-flyg** flyger över och släpper fallskärms-**powerup**
- [ ] Lådan faller mjukt till marken (ingen pass-through / hopp / snap off-screen)
- [ ] Parachute/crate: **`powerup`**-attachment under Deploy/Land; **`powerup_no_parachute`** efter landning
- [ ] Hjälten kan röra sig under passet; gå till lådan och **plocka upp** (HP / bunker / vapen / ammo)
- [ ] **Ingen preview** på lådan under fall — celebration **efter pickup** (mitten av skärmen)
- [ ] Efter pickup: **PowerUpTitle**, **PowerUpImage**, **PowerUpText** visar rätt belöning ~3 s
- [ ] **Ammo för vapen du inte äger** droppas **inte** (t.ex. ingen Flamethrower ammo före unlock)
- [ ] **Weapon unlock** för samma vapen ger refill om redan ägd (acceptabelt)
- [ ] Nästa våg startar efter supply-pass (ingen soft lock)
- [ ] Dev-genväg: `WaveConfig_V2` → **Open Swedish Plane Supply Directly** (våg 1) för isolerat test
- [ ] Life Over → retry fungerar i Survival

### 14.3 Game Over & high score

- [ ] Efter 3 liv: Game Over UI med Survival-poäng (bästa våg / kills denna run)
- [ ] Nytt rekord uppdaterar **High Score** på huvudmenyn
- [ ] **High Score**-panel visar sparade bests efter omstart av spelet

### 14.4 Save / Continue (Survival)

- [ ] Paus mitt i Survival → **Continue** återupptar samma läge och våg
- [ ] **Start Campaign** rensar save och startar Campaign (inte Survival)
- [ ] Campaign-save + **Continue** → inte Survival (och tvärtom)

## Definition of Done (EA 0.1.0)

Alla måste vara gröna:

- **Fas 8** — Game Over
- **Fas 14** — Survival mode (endless + high score + save per läge + svenskt supply-flyg / powerups + pickup HUD + ammo-regler)
- **Fas 1.4** — Main menu introfilm (valfritt om EA-ship kräver det — verifiera om aktiv i build)
- **Fas 9** — Save / load
- **Fas 4** — Shop
- **Fas 3** — HUD

Dessutom:

- **Fas 10** — Campaign våg 1–15 spelbara (balans kan vara “good enough”)
- **Fas 13** — Campaign Game Won
- **Fas 11** — Desktop + minst 4:3 + ultrawide gröna
